# Playerok-бот с уведомлениями в VK

Бот автоматически отвечает покупателям на Playerok, задаёт 3 вопроса (тип бота, формат выдачи, ссылка на аккаунт) и пересылает все ответы продавцу в VK.

## Возможности

- Автоматическое приветствие и 3-шаговый опрос покупателя
- Команда `+от` — ответ на вопрос (пересылается продавцу в VK)
- Команда `+позвать` — уведомление продавцу о вызове
- Дедупликация сообщений (не отвечает дважды на одно сообщение)
- Сохранение состояния в JSON (переживёт перезапуск)
- Автоматическая переподключение при обрыве соединения
- Готов к запуску в Docker, GitHub Actions 24/7, GitLab CI

## Установка

### 1. Настройка окружения

```bash
cp .env.example .env
```

Заполните переменные в `.env`:

| Переменная | Описание |
|---|---|
| `PLAYEROK_COOKIES` | Cookie из браузера (с токен-значением от Playerok) |
| `PLAYEROK_USER_AGENT` | User-Agent браузера |
| `VK_GROUP_TOKEN` | Токен API сообщества VK |
| `VK_SELLER_USER_IDS` | Числовые ID продавцов через запятую |

### 2. Запуск локально

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1  # Windows
pip install -r requirements.txt
python main.py
```

### 3. Запуск в Docker

```bash
docker compose up --build
```

## Команды покупателя

| Команда | Действие |
|---|---|
| `+от текст` | Ответить на вопрос бота |
| `+позвать` | Позвать продавца (уведомление в VK) |

## GitHub Actions (24/7)

Бот запускается автоматически каждые 40 минут через cron. Каждая сессия может работать до 5.5 часов.

### Настройка

1. Перейдите в **Settings -> Secrets and variables -> Actions** в репозитории.
2. Добавьте 4 секрета: `PLAYEROK_COOKIES`, `PLAYEROK_USER_AGENT`, `VK_GROUP_TOKEN`, `VK_SELLER_USER_IDS`.

## GitLab CI

- `test` — запускается при каждом push
- `build` — собирает Docker-образ (ручной запуск)
- `deploy` — деплоит через SSH на сервер (ручной запуск)

## FAQ

**Как получить PLAYEROK_COOKIES?**
1. Откройте Playerok в Chrome.
2. F12 -> Application -> Cookies -> playerok.com.
3. Скопируйте значения cookie (особенно `token`).

**Как получить VK_GROUP_TOKEN?**
1. Настройки сообщества -> Управление -> API.
2. Создать токен с правами `messages`.
3. Включите «Личные сообщения» в настройках сообщества.

**Продавец не может получить сообщения от бота в VK**
Продавец должен хотя бы раз написать в сообщения сообщества — VK блокирует инициацию диалога со стороны сообщества.
